# [!DNL Adobe System Status] リリースノート {#status-release-notes}

[!DNL Adobe System Status] では、アドビ製品およびサービスに関する詳細情報、ステータス更新およびメール通知を提供します。 停止、中断およびメンテナンスイベントに関する通知を受け取れます。 [status.adobe.com/ja](https://status.adobe.com/ja){target="_blank"} でご確認ください。

このページは[!DNL Adobe System Status]件の更新を経時的に追跡します。 レポートする新しいリリースがある場合にのみ更新されます。

| 日付 | アップデート |
| ------- | ------- |
| 2026 年 3 月 | <ul><li>AI バーチャルアシスタント（Beta）</li><li>バグ修正と改善</li></ul> |
| 2025年12月8日（PT） | <ul><li>バーチャルアシスタントのフィードバック機能の強化（ガイド付きワークフローの合理化、直感的なアイコン）</li><li>バグ修正と改善</li></ul> |
| 2025年7月16日（PT） | <ul><li>仮想アシスタントの一般提供</li><li>製品ページおよびクラウドページ、およびバーチャルアシスタントでのイベント ID検索</li><li>Slack 通知設定の更新</li><li>バグ修正と改善</li></ul> |
| 2025年3月20日（PT） | <ul><li>仮想アシスタントベータ版</li><li>新しいイベント用語集のヘルプページ</li><li>バグ修正と改善</li></ul> |
| 2024年8月19日（PT） | <ul><li>製品ベースのメンテナンス通知（強化されたUIと製品ごとの通知）</li><li>バグ修正と改善</li></ul> |

| 2023年3月 | <ul><li>新しいアップデートはありません。最新の機能については、2023年1月（ステータス API）を参照してください。</li></ul> |
